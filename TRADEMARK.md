# TsVRC name and logo

TsVRC is the name [Antony Seas](https://github.com/ToniSeas) publishes VRChat tools under. It's a
personal project, not a company, and "TsVRC" isn't a registered trademark. The license of each
repository covers its code or docs, not the TsVRC name or logo.

## Fine without asking

- Mentioning TsVRC and its projects by name, linking to them and writing about them.
- Saying your work uses or works with a TsVRC project, such as "built with TsVRC Core" or "tested
  with Udon Test Kit", when it does.
- Sharing an unmodified release under its own name.

## Ask first

- Using the TsVRC logo.
- Putting the TsVRC name in the name of your own project, package, world or domain.
- Anything that makes your work look like it's TsVRC, or like Antony Seas made or endorses it.

If you publish a modified version of a TsVRC project, give it a name of its own. It can say which
project it's based on.

To ask, or for any question, email [contact@tsvrc.com](mailto:contact@tsvrc.com).
