# Trademark policy

"TsVRC" and any associated logos identify the official TsVRC project (`tsvrc-core`,
`docs`, and any other repository under the [`tsvrc`](https://github.com/tsvrc) GitHub
org) and its maintainer, Antony Seas. This is separate from the code and content
licenses: the Apache-2.0 license on `tsvrc-core` and the CC BY 4.0 license on `docs`
grant rights to the code and content, not to the TsVRC name or logo (see each repo's
`NOTICE`/`LICENSE`).

## What this means for forks and derivative works

You're free to fork, modify, and redistribute TsVRC's code and docs under their
licenses. If you do:

- Don't use "TsVRC" or its logo to imply your fork is the official project, or that it's
  endorsed by or affiliated with the original.
- If your fork or derivative work is meaningfully different from upstream, name it
  something else, or clearly mark it as an unofficial fork (for example, "MyFork, based
  on TsVRC").
- Don't use the TsVRC name in a way that could confuse users about who maintains what
  they're using, especially anywhere money changes hands (a paid asset, a commissioned
  world) or where support expectations are set.

This is a lightweight version of the same policy used by projects like Rust, Node.js,
and the Python Software Foundation. No trademark is currently registered; this policy
relies on ordinary trademark and unfair-competition law protecting a name in active,
consistent use, and on GitHub's own impersonation/trademark policies for enforcement.
Formal registration may happen later if it becomes worth the cost.
