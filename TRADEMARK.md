# TsVRC name and logo

TsVRC can sound like a company or an official brand, but it's a personal project, built
and maintained by [Antony Seas](https://github.com/ToniSeas). "TsVRC" isn't a registered
trademark either, it's just the name given to the project.

The Apache-2.0 and CC BY 4.0 licenses this project ships under cover the code and the
docs, not the name or the logo. Mentioning TsVRC by name, linking to it, or writing about
it is normal and welcome. The only ask: don't use the name or logo in a way that makes
something look like it's TsVRC itself, or like Antony Seas made or endorses it, when
that's not the case.

Questions? Contact [contact@tsvrc.com](mailto:contact@tsvrc.com) or
[@ToniSeas](https://github.com/ToniSeas) directly.
