# TsVRC

TsVRC builds open-source tools for VRChat world and avatar creators. Not affiliated with,
endorsed by, or sponsored by VRChat Inc.

- [tsvrc-core](https://github.com/tsvrc/tsvrc-core): the UdonSharp framework, with
  structured initialization, dependency wiring, and editor codegen.
- [docs](https://github.com/tsvrc/docs): documentation for every project under this org,
  at [tsvrc.com](https://tsvrc.com).

New here? Start with the [docs](https://tsvrc.com). Found a bug or have an idea? Open an
issue on the relevant repo above, or see [SUPPORT.md](SUPPORT.md) for where else to go.
