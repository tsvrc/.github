# Hi, I'm [Toni](https://github.com/ToniSeas)

I build tools for making VRChat worlds. TsVRC is the name I publish them under, and most of them
are open source.

- [Core](https://github.com/tsvrc/tsvrc-core): a structured way to build VRChat worlds with
  UdonSharp, with consistent startup, wired-up dependencies, and generated code instead of
  hand-wiring everything yourself.
- [Udon Test Kit](https://github.com/tsvrc/udon-test-kit): automated tests for VRChat worlds. Play
  Mode tests run your UdonSharp behaviours in a real ClientSim session, with real players.

The docs for both are on [tsvrc.com](https://tsvrc.com), and the Creator Companion installs them
from [vpm.tsvrc.com](https://vpm.tsvrc.com). Questions and ideas go in
[Discussions](https://github.com/orgs/tsvrc/discussions), and
[SUPPORT.md](https://github.com/tsvrc/.github/blob/main/SUPPORT.md) says where everything else
goes. If you'd like to support what I make, there's [tsvrc.com/support](https://tsvrc.com/support).

*TsVRC isn't affiliated with, endorsed by, or sponsored by VRChat Inc.*
