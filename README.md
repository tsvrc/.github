# .github

Default community files for the `tsvrc` org: the code of conduct, `SUPPORT.md`, the funding links,
the pull request template and the issue template settings. GitHub uses each one in any repository
that doesn't have its own, as described in
[Creating a default community health file](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
`profile/README.md` is the org profile at [github.com/tsvrc](https://github.com/tsvrc).

`GOVERNANCE.md` and `TRADEMARK.md` aren't defaults GitHub falls back to. They're here because they
apply to every repository, and the projects link to this copy.
